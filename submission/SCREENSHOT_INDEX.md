# Screenshot package

The `screenshots/` folder contains six App Store screenshot candidates composed from the project’s UI design HTML and current product/brand specification. Each 6.7-inch PNG is **1290 × 2796 px**; the `6.5-inch/` set is **1284 × 2778 px**.

| Order | File | Store caption | What it demonstrates |
|---:|---|---|---|
| 1 | `01_start_in_one_tap.png` | Start in one tap. | Countdown timer, simple start action, BPM control. |
| 2 | `02_find_your_pace.png` | Find your pace. | Active run state, live metrics, metronome, stop protection. |
| 3 | `03_quietly_celebrate.png` | Quietly celebrate. | Completion summary, goal progress, streak, share entry point. |
| 4 | `04_see_the_pattern.png` | See the pattern. | Month report, metric cards, trend chart, session log. |
| 5 | `05_keep_it_close.png` | Keep it close. | Home Screen widget concepts for today, streak, and total time. |
| 6 | `06_make_it_yours.png` | Make it yours. | Settings, language, theme, training defaults, and local data choice. |

## Upload note

These are polished marketing candidates, not a substitute for captures from the final signed binary. Before upload, run the archived build on the target simulator/device, capture the same six states, and replace the PNGs if any visible behavior differs. Do not upload a screenshot that shows an unavailable feature or placeholder data.
