# Niko Neko Run 送審材料包

這個資料夾是 App Store Connect 送審用的工作包：

- `APP_STORE_METADATA.md`：繁中／英文名稱、副標題、宣傳文字、關鍵字、完整描述與 What's New。
- `REVIEW_NOTES.md`：給 Apple 審查員的測試路徑、權限用途、硬體與資料說明。
- `PRIVACY_POLICY.md`、`privacy-policy.html`：隱私政策文字版與可部署的網頁版。
- `support.html`：可部署的支援頁草稿。
- `APP_PRIVACY_ANSWERS.md`：App Privacy 問卷的建議答案與重新檢查條件。
- `screenshots/`：6 張 6.7 吋（1290×2796）與 6.5 吋（1284×2778）截圖候選。
- `assets/NikoNekoRun_AppIcon_1024.png`：1024×1024 App icon。
- `SCREENSHOT_INDEX.md`、`SUBMISSION_CHECKLIST.md`：素材索引與上傳前清單。

重要：截圖是依目前 UI 設計與產品規格製作的高解析宣傳候選；正式送審前，請用最終簽署 build 在實機／模擬器重新擷取同樣狀態，確認畫面與功能一致後再上傳。`<your-domain>` 與 support email 也要換成正式公開資訊。
