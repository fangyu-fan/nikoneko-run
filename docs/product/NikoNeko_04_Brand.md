## Brand Foundation

### Mission

Make slow jogging a daily habit that feels effortless, satisfying, and worth coming back to.

### Vision

The app that serious slow joggers keep on their home screen — not because it does everything, but because it does one thing beautifully.

### Promise

Open the app. Tap play. Run. Everything else fades away.

## Naming

### English

**NIKO NEKO**

| Element | Origin | Meaning |
|---------|--------|---------|
| NIKO | ニコニコ (Japanese) | Smile / cheerful — refers to "niko niko pace", the intensity at which you can run while smiling |
| NEKO | ねこ (Japanese) | Cat — the app's character and mascot |

Two syllables each. Rhyming. Memorable. The double-word rhythm mirrors the repetitive cadence of jogging itself.

**Tagline:** *slow jog · smile pace*

### Chinese

**慢跑貓貓**

- 慢跑 — slow jog, immediately communicates function
- 貓貓 — affectionate doubling of 貓 (cat), warmer and more playful than a single 貓
- The doubling rhythm echoes NIKO NEKO

### Usage Rules

| Context | Format |
|---------|--------|
| App icon | NIKO NEKO (all caps) or graphic mark only |
| App Store title | Niko Neko |
| App Store subtitle | 慢跑貓貓 · slow jog · smile pace |
| In-app (English) | Not shown — the app is icon-only in the UI |
| In-app (Chinese) | Not shown |
| Marketing / social | NIKO NEKO |
| Casual / human text | niko neko (lowercase acceptable) |

## Personality & Voice

### Three Core Traits

**Focused**
NIKO NEKO doesn't try to be a fitness platform. It does one thing: help you slow jog, every day. The UI, the copy, the features — all serve this single purpose. Nothing is added for the sake of it.

**Minimal**
Less is more in every dimension. Fewer words. Fewer buttons. More breathing room. The brand communicates through restraint — what is left out is as intentional as what stays.

**Healthy**
Not "wellness" in the commercialized sense. Genuinely healthy — consistent daily movement, sustainable pace, no pressure. The slow jog philosophy is built into the brand: progress is quiet, cumulative, and kind.

### Tone of Voice

| Situation | Tone |
|-----------|------|
| Onboarding | Calm, brief, no hype |
| Timer screen | Silent — no text during a run |
| Notifications | Gentle reminder, never urgent |
| Summary screen | Quietly celebratory |
| Error messages | Direct, solution-focused, never apologetic |
| Marketing | Confident, dry wit, no exclamation marks |

### What the voice sounds like

```
✓  "Run. Nothing else."
✓  "12 days. Keep going."
✓  "21 minutes today."
✗  "Amazing work! You crushed it! 🎉"
✗  "Don't forget to jog today!"
✗  "Your health journey starts here."
```

## Audience

### Primary Persona

**The Daily Slow Jogger**

- Age 25–55
- Already practices or is starting slow jogging
- Values consistency over intensity
- Finds most fitness apps overwhelming or cluttered
- Uses iPhone as their primary device
- Has Apple Watch or is considering one
- Cares about the aesthetic of their home screen

### What they want from an app

1. Start their run in under 3 seconds
2. Know their time and heart rate at a glance
3. See their streak without opening the app
4. Not be distracted during the run
5. Look back at their progress simply

### What they do not want

- Gamification badges and confetti
- Social features or leaderboards
- Subscription pressure
- A dashboard that takes 10 seconds to read

## Visual Identity

### Design Philosophy

**One typeface. One weight. One hierarchy.**
The brand doesn't use decorative elements. The logo is the name set in type. The icon is a silhouette. The illustrations are two-color maximum.

**Dark as the natural state.**
The primary brand expression is dark — near-black with a single accent. Light versions exist but are secondary. This mirrors the app's default Obsidian theme.

**The cat is always running.**
The mascot is never static in motion contexts. Animation is the brand's primary visual expression.

## App Icon

### Concept

A white cat silhouette mid-run on a near-black background. The same style as the in-app characters — filled shape, no outlines, no gradients.

### Specifications

| Property | Value |
|----------|-------|
| Background | #0a0a0a (Obsidian) or theme-matched |
| Silhouette color | #f0ede8 (warm white) |
| Style | Filled silhouette, no outlines |
| Shape | iOS squircle (system-applied) |
| Content safe zone | 10% inset from all edges |
| Animation | Static (icon), animated in Spotlight / App Library if supported |

### Variations

| Variant | Usage |
|---------|-------|
| Default dark | App Store, home screen |
| Light | Alternate icon (user-selectable in Settings) |
| Theme-matched | Optional: icon bg matches active theme |

### What to avoid

- Text in the icon
- Drop shadows or glows
- More than two colors
- Gradients
- A cartoon face with eyes and mouth (too Rumbo / too cute — our cat is a silhouette)

## Typography

NIKO NEKO uses **system fonts only** — SF Pro on iOS.

### Hierarchy

| Level | Weight | Size | Usage |
|-------|--------|------|-------|
| Display | Ultralight (200) | 68–72 pt | Timer numeral |
| Title | Medium (500) | 14–16 pt | Screen titles, tab labels |
| Body | Regular (400) | 12–13 pt | Content, lists |
| Caption | Regular (400) | 9–10 pt | Labels, dates, units |
| Micro | Regular (400) | 7–8 pt | Widget cells, chart axes |

### Rules

- No custom fonts — SF Pro is part of the brand's iOS-native identity
- Numerals always use tabular figures
- Large numerals use negative letter-spacing (−2 to −3 pt)
- All-caps labels use +0.08em letter-spacing
- No bold text below 11 pt

### Brand Name in Type

When typeset as text (not icon):

```
NIKO NEKO
```

- All caps
- SF Pro Display or any clean grotesque
- Letter-spacing: +0.06em
- No ligatures
- Single space between words

## Color

### Brand Palette

The brand has one primary palette (dark) and one secondary palette (light). All other app themes are user choices — not brand expressions.

#### Primary (Dark)

| Token | Hex | Name | Usage |
|-------|-----|------|-------|
| Brand Black | `#0a0a0a` | Obsidian | Backgrounds, icon bg |
| Brand White | `#f0ede8` | Warm White | Primary text, silhouettes |
| Brand Dim | `#2e2e2e` | Charcoal | Secondary surfaces |
| Brand Mid | `#888888` | Stone | Muted text, inactive states |

#### Secondary (Light)

| Token | Hex | Name | Usage |
|-------|-----|------|-------|
| Brand Cream | `#f4f0ea` | Limestone | Light bg |
| Brand Ink | `#1c1a16` | Deep Ink | Light text |
| Brand Sand | `#d0c8b8` | Sand | Light dividers |

#### Accent (Marketing only)

For App Store screenshots, website, and promotional materials — pick **one** accent per campaign, drawn from the app's theme palette. Never mix multiple accents.

Recommended for default brand materials:

| Hex | Theme | Usage |
|-----|-------|-------|
| `#71c4ef` | Skyline ice blue | Light-mode marketing |
| `#acc2ef` | Navy periwinkle | Dark-mode marketing |

### Color Rules

- **Never use bright saturated color** in brand materials unless it's a deliberate campaign choice
- The cat silhouette is always `#f0ede8` on dark, `#1c1a16` on light
- No gradients in brand identity (gradients are for themes only)
- Marketing backgrounds should be Obsidian or Limestone — not theme colors

## Motion & Tone

### The Running Cat

The cat animation is the brand's primary motion asset. It appears:

- On the App Store preview screenshots (animated)
- In App Store preview video
- On any website or marketing material where motion is supported

### Animation Rules

- The cat is **always running** in motion contexts — never standing, never jumping, never doing something unrelated
- Speed is always **moderate** in marketing — not frantic, not slow. It mirrors 180 BPM slow jog pace.
- Color: always `#f0ede8` on dark, `#1c1a16` on light
- Never add a face, eyes, or expression — the silhouette is expressive enough

### Transitions

- All transitions in marketing materials mirror the app: clean, no bounce, no spring physics
- Standard ease-in-out, ~0.3 s
- No parallax, no 3D transforms

## Copy Guidelines

### Do

- Short sentences. One idea per sentence.
- Present tense.
- Direct address ("your run", "your streak").
- Numbers without decoration ("12 days", "21 min").
- Japanese words only if they're the brand name or a known term (niko niko pace).

### Don't

- Exclamation marks (ever).
- Emoji in UI copy (the cat animation is the emotion).
- "Journey", "wellness", "transform", "crush it", "level up".
- Passive voice.
- Apologies ("sorry, something went wrong" → "Couldn't save. Try again.").

|---------|----|----|

## What NIKO NEKO Is Not

Clarity on what the brand deliberately avoids:

| Not this | Why |
|----------|-----|
| A gamified fitness app | No badges, no points, no leaderboards |
| A social running platform | No sharing feeds, no challenges with others |
| A coaching app | No plans, no instructions, no "you should" |
| Cute / kawaii | The cat is a silhouette — refined, not adorable |
| Corporate wellness | No motivational posters, no stock photo energy |
| Aggressive | No streaks broken notifications, no guilt |

The brand sits in the space between **tool** and **companion** — present when you need it, invisible when you don't.
